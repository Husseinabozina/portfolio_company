03 · AI-native engineering

Agents write fast.
I make sure it's right.

I treat AI coding agents like a very fast team: they need a clear spec, the right context and a strict reviewer. That is the job I do, on every feature.

01

Spec-driven development

Every feature starts as a written spec: user flows, edge cases, API contracts and acceptance criteria. The agent builds against that spec, never against a vague prompt.

02

Context engineering

Architecture rules, naming conventions, BLoC and Clean Architecture patterns and the exact files involved go in deliberately, so generated code reads like it belongs in the codebase.

03

Agentic implementation

Agents take the volume: scaffolding, boilerplate, refactors and tests. I split work into small, bounded tasks so each run stays focused and easy to check.

04

Verification gates

Nothing merges on trust. I anticipate likely failure modes, review every diff, and run tests and CI before I accept a change. What ships is my responsibility.

The agents I run, and the models behind them

I pick the agent and model per task: long refactors, quick UI iterations, test generation or code review.
